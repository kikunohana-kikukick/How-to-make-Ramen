# Toppings Counter

Toppings bring texture, color, and contrast to ramen. Each file in this folder should focus on one topping so it can be reused across multiple recipes.

## Start here

- `chashu.md` — braised pork
- `ajitama.md` — seasoned soft-boiled eggs
- `menma.md` — seasoned bamboo shoots
- `scallions.md` — sliced green onions

## Topping recipe format

Include:
1. Yield or number of portions
2. Ingredients and quantities
3. Numbered preparation steps
4. Storage and food-safety notes
5. Variations and substitutions

Keep optional garnishes clearly marked. When using meat or eggs, explain safe handling and refrigeration.
