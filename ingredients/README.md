# Ingredients Pantry

This folder explains ingredients used across the cookbook. Individual notes should describe flavor, how an ingredient is used, and accessible substitutes.

## Common ramen ingredients

| Ingredient | What it adds | Possible substitute |
| --- | --- | --- |
| Soy sauce | Saltiness, color, savory flavor | Use a suitable gluten-free tamari if needed; check labels |
| Miso | Fermented, savory depth | Different miso varieties can be swapped, though flavor changes |
| Kombu | Gentle umami | Omit if unavailable; the broth will taste different |
| Dried shiitake | Earthy, savory depth | Fresh mushrooms add a different flavor |
| Sesame oil | Toasted aroma | Use another neutral oil only if sesame is unsuitable; flavor will change |
| Spring onions / scallions | Fresh, sharp garnish | Chives can work in a pinch |
| Noodles | Texture and structure | Use fresh or dried ramen noodles; check cooking instructions |

## Pantry conventions

- List allergens when known, including soy, wheat, sesame, egg, and fish.
- Check packaging for hidden allergens and cross-contact warnings.
- State whether an ingredient is optional.
- Suggest substitutions without promising an identical result.

## Add an ingredient note

Create a file such as `soy-sauce.md` with a description, common uses, storage guidance, and substitution notes.
